### B3. 枢纽—辐射模型（Hub-and-Spoke）落地建议

**应长期维护的"数据枢纽页"（Data Hub）**

| 枢纽页 | 文件（建议） | 内容 | 更新周期 | 反向回链目标 |
|---|---|---|---|---|
| 机票价格动态 | `price.html`（已有） | 12+ 航线最低价/均价/环比表 | 每周二、五 | → C2/C3/C4/C5 |
| 航司会员日一览表 | `airlines-member-day.html`（新） | 各航司会员日日历（南航28/东航18/国航15/海航8/春秋27…） | 每月 | → 各航司专题段、airlines.html |
| 燃油附加费标准表 | `fees-fuel-surcharge.html`（新） | 各航段燃油附加费 / 机建费标准 | 每月 | → C21、airlines.html |
| 各航司行李额度对比表 | `airlines-baggage.html`（新） | 免费托运 / 超重计费 / 随身携带对比 | 每季 | → C12、C17、airlines.html |
| 城市机场对比表 | `routes-airport-compare.html`（新） | 首都/大兴、虹桥/浦东、双流/天府 | 每季 | → C9、routes.html |

**枢纽之间如何互链**
- **"共同影响总价"的四张表互链成环**：`会员日日历 ↔ 促销日历 ↔ 燃油费表 ↔ 行李表`——因为用户判断"是否划算"时，会把票价 + 燃油费 + 行李费 + 促销叠加起来算，天然适合互相跳转。
- **每张表反向回链到"航司专题段"**：如行李表每一行"该航司额度"→ `airlines.html` 对应航司动态；燃油费表 → `airlines.html`。
- **每篇解读文回链其数据枢纽**：C13 退改陷阱 → 行李表；C11 第一次坐飞机 → 行李表；C2 价格规律 → 价格动态页。

**为什么这类页面适合做长期回访入口**
1. **结构化、可截图可分享**：表格页天然被收藏与自然外链引用（brief 第 6 节已指出），是低成本外链入口。
2. **周期更新、时间衰减低**：会员日/燃油费/行李规则**按月/按季复核**，内容常新，回访率稳定。
3. **内链枢纽属性强**：一个数据页可向下辐射多篇解读文，向上回链栏目页，是聚类"权重集散点"。
4. **契合站点差异化**：OTA 与垂直媒体都不愿长期维护这些"琐事表"，正是机票.CC 的"中立 + 结构化数据护城河"。
