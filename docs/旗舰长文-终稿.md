# 机票什么时候买最便宜？提前多久订的完整时间表（国内 / 国际 / 淡旺季）

**先说答案：机票什么时候买最便宜，取决于航线类型——国内航线通常提前 3–8 周，国际航线提前 2–6 个月，落在这两个区间的低价舱位最多。** 但这不是背下来就能套用的数字。真正决定价格的是航司的收益管理：同一个座位被拆成几十个不同价格的舱位，最便宜的卖完，下一档立刻变贵。看懂这套机制，你就能自己判断现在该买，还是再等等。

> - "周二抢票"被高估：**下单日**对价格影响很小（约 1% 量级），真正拉开差距的是**出发日**——周二至周四出发常比周末便宜约 13%（参考口径：Google Flights 2021–2025 年聚合数据，国际航线为主）。

> - 日期**不能改**，或撞上春节、国庆、寒暑假时，等待收益很低，尽早锁定更稳妥。
> - 判断现在买还是等等，看四个信号：距出发天数、余票松紧、历史价位、日期灵活度。

## 直接答案：机票什么时候买最便宜？提前多久订？

把"提前多久"按航线类型拆开，比记一个统一数字靠谱。下表综合了 Google Flights 近年（2021–2025）的公开聚合数据、几份公开票价研究，以及国内航司可见的售票规律。

| 航线类型 | 常见低价窗口（提前期） | 说明 |
|---|---|---|
| 国内短途（约 2 小时以内） | 提前 1–3 周 | 班次密、竞争充分，波动小，不必过早锁票 |
| 国内中长线（跨省，2–3 小时以上） | 提前 3–6 周 | 折扣舱通常在产品周期中段批量放出 |
| 国内热门旅游线 / 旺季 | 提前 1–2 个月，旺季再提前 | 低价舱上线即被抢，越晚越只剩高舱位 |
| 国际中短途（东南亚、日韩等） | 提前 1.5–3 个月 | 廉航与全服务航司放票节奏不同，波动较大 |
| 国际长航线（欧洲、北美等） | 提前 2–6 个月 | 舱位少、航季长，早段价格偏高，中段更稳 |

*价格窗口为区间参考，随季节、航线与促销变动，不构成报价。*

**机票价格规律**的核心是收益管理。为什么给区间而不是精确天数？因为一趟航班的客舱会被切成十多个到二十多个票价舱位，越便宜的越先卖，卖完就放下一档、价格上行。

反过来也一样：如果卖得慢，系统可能重开低价舱，或者干脆做促销。所以"最便宜"不是某个固定日子，而是**大多数低价舱还开着、航司又开始清仓的交叠区间**。

## 国内航线：提前多久订最合适？

**国内机票提前几天买最划算？** 短途 1–3 周、中长线 3–6 周是常见答案。国内规律好抓，把三种线分开看：

- **短途（约 2 小时内）**：提前 **1–3 周**即可，价格曲线平，早买省不了多少。
- **中长线（跨省）**：提前 **3–6 周**是常见低价区间，过早订可能还没进促销周期。
- **热门旅游线（三亚、成都、西安、青岛等）**：提前 **1–2 个月**开始盯，节假日再往前推。

关键机制：**低价舱位往往在出发前 3–8 周批量放出**。这就是为什么"提前半年订国内票"经常买贵——那时放的还是基线价，折扣没开始。公开票价研究也提示，提前 5–10 个月买国内票，常比最佳窗口高出一截。

所以国内票更像"中段出手"：太早没赶上促销，太晚挑不到低价舱，中间那段最舒服。不同航线的中段位置并不一样，可对照 → [航线资讯](routes.html) 里各航线的需求节奏。

## 国际航线：为什么和国内不一样？

判断**机票价格趋势**，国际线和国内线的看法不同。

国际线为什么不能照搬国内的节奏？关键在排班方式。国内加减航班相对灵活，国际线按航季走，想加密一班要提前很久安排，运力更"死"。再叠加税费、燃油附加费和跨境规则，成本结构也更复杂。

不过它有个好处：远程折扣舱几乎总是提前放出来，通常在出发前 2–6 个月，你反而有时间等。

一个常被引用的观察是：飞欧美等长航线，**提前约 50–100 天上下的价格通常最低**（参考口径：Google Flights 及多家公开票价研究，以国际航线为主）；春节、暑假等旺季则要**提前 3–6 个月**锁。

在深圳做外贸的老郑，一年飞法兰克福两三趟。他的规矩是"提前两个半月开始看，两周内拍板"。太早促销没出来，太晚好舱位没了。用他的话说："国际票不是越早越便宜，是在对的时间段下单才便宜。"

## 一周里哪天买最便宜？"周二更便宜"还成立吗？

先分清两件事：**"哪天买"** 和 **"哪天飞"**。

- **哪天飞**：影响明显。周二到周四出发普遍比周末便宜，周末常带 10%–25% 溢价，周日往往是全周最贵的一天（参考口径：Google Flights）。
- **哪天买**：影响很小。最便宜的下单日（周二）与最贵的下单日（周日）之间，差价只有约 1%，专门挑周二买票，省下的钱基本可以忽略。

所以"周二买机票便宜吗"，更接近的答案是：说周二**出发**，它确实便宜；说周二**下单**，那已经被高估了。现代航司定价算法一天调多次，早已不是按周更新票价的年代。

真正值得利用的是**把出发日往周中挪一挪**，这通常比纠结哪天下单实惠得多。怎么错峰，可配合 → [出行攻略](guides.html) 一起看。

## 一天中哪个时段可能捡漏？

流传较广的说法是：凌晨 0–3 点、下午 13–15 点容易捡漏，理由是"清理未支付订单"和"退改余票回库"。客观说，**这类时段捡漏更像经验观察，不是稳定规律**。动态定价普及后，价格随时可动，所谓"低价时段"并不保证成立。

把它当作**可尝试但别指望**的选项即可，别当成必省技巧。更稳的做法是盯住该航线的历史价位区间，落到低位就出手：见文末清单。

## 淡旺季与节假日：什么时候提前量要拉长

同一条航线，淡季提前 3 周和旺季提前 3 周，完全是两回事。

- **需大幅提前**：春运、国庆、暑期（约 7–8 月）、春节前后的热门旅游线。这些时段低价舱**上线即被抢**，建议在常规律基础上**再提前 2–4 周甚至更久**。
- **相对便宜的窗口**：春节后到清明前后、国庆后到元旦前的淡季，票价常有明显回落，适合错峰。
- **按具体节日定**：公开数据显示，春节、圣诞等大节的最便宜购票点通常落在节前**约 1 个月到 1 个半月**（参考口径：Google Flights），比日常更早。

说到底，旺季拼的不是"哪天最便宜"——那个最低点往往并不存在。你要避免的是拖到票快卖完，只能被动接受高价。

## 什么情况下"等一等"是错的

不是所有时候都该等。以下几类，等待大概率是错的：

1. **日期完全不能动**（出差、看演出、参加婚礼）：你面对的是买不到的风险，早锁更安全。
2. **余票已经偏紧**：可选日期与舱位组合变少时，再等等常等来更贵甚至没票。
3. **赶上明确高峰**：春运、国庆、暑期热门线供不应求，价格往上走，等不来降价。
4. **票价已在低位**：现价接近该航线历史低位时，见好就收。

小张今年春节提前两个月订了上海到三亚的票，含税 1800 元。出发前一周随手一查，同班降到 1100 元。

他打航司客服，用"买低退高"退了高价票、重买低价票，省下一笔。但这类政策不是每家都有。据报道，部分航司（如东航、南航等）在特定条件下曾提供过类似安排，也有航司并未开放。

**能不能走通，取决于你买的航司与当时规则。** 购票前先问清楚，别把它当成默认权益。相关变动可关注 → [航司动态](airlines.html)。

## 怎么判断"该现在买还是再等等"？决策清单

照着走：

1. **算提前期**：距出发还有多少天？对照时间表，你在窗口前、中还是后？
2. **看日期灵活度**：能改就还有等的空间；不能改，倾向早锁。
3. **看余票松紧**：偏紧就该动，别等。
4. **比历史价位**：现价比该航线的常见区间偏高还是偏低？（可在 → [机票价格动态](price.html) 找参照）
5. **查是否旺季**：撞上高峰，就把结论整体前移。
6. **设机票降价提醒再决定**：决定等，就设价格提醒，并定一条"到什么价就买"的底线。

| 你的情况 | 更建议 | 原因 |
|---|---|---|
| 国内短途、日期可改、余票充足 | **可以再等等** | 价格曲线平，等待成本低 |
| 国内中长线、处于提前 3–6 周窗口 | **现在买** | 低价舱批量放出的区间 |
| 国际长航线、距出发 2–6 个月 | **开始盯，择机买** | 促销窗口就在这段 |
| 日期不能改 / 余票偏紧 | **尽早锁** | 面对的是买不到的风险 |
| 春运、国庆、暑期热门线 | **大幅提前锁定** | 供不应求，越等越贵 |
| 现价已在历史低位 | **见好就收** | 赌更低价的收益有限、风险不小 |

## 常见问题 FAQ

### Q1：机票什么时候买最便宜？提前多少天？

国内通常提前 3–8 周、国际提前 2–6 个月，低价舱最多。旺季要在常规律上再提前。国内提前半年以上未必便宜，因为航司初期放的票价偏高。

### Q2：周二买机票真的更便宜吗？

分开看：周二**出发**通常比周末便宜；周二**下单**的优势很小，最便宜与最贵的下单日只差约 1%，基本可忽略。

### Q3：为什么我提前买了还降价了？

票价是动态的。航司临近起飞若客座率不高，可能降价吸引旅客，即"跳水"。关于"买低退高"，部分航司在特定条件下提供过类似安排，也有航司并未开放，能否退差价取决于航司与当时规则。

### Q4：国内和国际机票，提前期为什么差这么多？

国际按航季排班、运力刚性、成本复杂，促销也更早；国内班次密、竞争充分，价格窗口更靠后也更平。

### Q5：凌晨或下午真的能捡漏吗？

可以尝试，但别依赖。动态定价下低价时段不稳定；更可靠的是盯该航线历史价位，落到低位就买。
