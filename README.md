# 机票.CC · 机票资讯网站

> **不卖票的机票信息站** —— 把「机票什么时候买、怎么买才不亏」这件事，用可核对的数据和中立的态度讲清楚。
>
> 域名：`机票.CC`（punycode `xn--yetu496a.cc`）

本仓库是 [机票.CC](https://xn--yetu496a.cc) 的完整前端源码与内容规划产物。站点为**纯静态站点**，无后端、无数据库、无构建依赖，可直接托管于 GitHub Pages / 任意静态服务器。

## 一、站点定位

| 项目 | 内容 |
|---|---|
| 定位 | 中立机票资讯与信息聚合站点 |
| 边界 | **不销售机票、不代收票款、不参与交易、不为具体票务机构导流** |
| 差异化 | ① 中立性（敢做平台横评与避坑）② 结构化数据沉淀（会员日日历、行李额度对比等可复用表格页）③ 出行决策陪伴（用旅客语言讲） |

## 五、本地构建

站点 HTML 由 `build.py` 从单一数据源生成，修改内容后重新生成即可：

```bash
python build.py
```

生成内容：7 个栏目页 + 首页 + 文章页 + `assets/js/data.js` + `robots.txt` + `sitemap.xml`。

预览：直接用浏览器打开 `index.html`，或

```bash
python -m http.server 8080
```

## 六、SEO 与合规基建（已内置）

- 每页独立 `title` / `description` / `canonical` / Open Graph 标签
- JSON-LD 结构化数据：`WebSite` / `Organization` / `BreadcrumbList` / `ItemList` / `Dataset` / `Article` / `FAQPage` / `AboutPage`
- E-E-A-T：页面级「最后更新 + 下次复核」更新戳；数据页标注来源与统计口径；价格一律给区间并区分裸票价 / 含税总价 / 燃油附加费 / 民航发展基金
- 全站页脚免责声明：本站不提供机票销售与交易服务
- 未使用关键词堆砌、隐藏文本等作弊手法

## 七、重要声明

站内价格、航班、活动等均为**示例数据**，仅用于演示页面结构与交互，不构成任何报价或购票依据。正式上线前须替换为已核验的数据源，并在页面标注真实来源与更新时间。
